## **What is SPECKit Plus?** 

[SPECKit Plus](https://github.com/panaversity/spec-kit-plus) is a Spec-Driven Development (SDD-RI) framework that helps you write clear and detailed specifications *before* generating any code.
Instead of producing random or unclear output, you:

* **specify** (describe exactly what you want)
* **plan** (define constraints, architecture, and a checklist of tasks)
* **tasks** (break the work into small, manageable units)
* **implement** (execute each task step by step)

SPECKit Plus ensures the AI’s output aligns with the project needs exactly as intended.

---

## 5 Core Concepts of SPECKit Plus

### ```/constitution```

Defines the overall standards, rules, and guidelines that apply across the entire project.

### ```/specify```

Writing complete specifications that clearly state what needs to be built.

### ```/plan```

Turns the specification into an implementation plan and records architecture decisions (ADRs).

### ```/tasks```

Breaks the plan into smaller, trackable units with clear checklists.

### ```/implement```

The phase where all tasks are executed with AI assistance.
